一条你可以检查的审查流水线

宿主模型负责理解代码，共享协议控制审查范围并过滤薄弱结论；可选 CLI 提供确定性的代码位置验证。

  1. 01

    映射完整 diff

    分析细节前先枚举所有变更文件与代码块，并跳过二进制、生成文件和敏感信息。

  2. 02

    构建有限上下文

    只追踪证明或推翻候选问题所需的调用方、类型、测试和项目规则。

  3. 03

    质疑每个发现

    第二轮检查触发条件、影响、因果关系、行范围与可能的反证。

  4. 04

    只报告有效信号

    最多返回十个按优先级排序的问题，支持 Markdown 或 JSON；没有问题就明确给出干净结果。

从本地开始

使用你已经信任的智能体

选择一个平台。默认工作流不增加模型网关，也不会发送遥测数据。

克隆仓库后，只需一条命令即可注册并安装 Codex Skill。

npm run install:agents -- --platform codex

然后输入： $auto-code-review review my current changes

克隆仓库后，只需一条命令即可注册并安装带命名空间的 Claude Skill。

npm run install:agents -- --platform claude

然后运行： /auto-code-review:review
