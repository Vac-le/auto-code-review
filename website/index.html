Evidence before opinion

A review pipeline you can inspect

The host model reasons about code. A shared protocol controls scope and filters weak output; the optional CLI adds deterministic location validation.

  1. 01

    Map the complete diff

    Enumerate changed files and hunks before analyzing details. Skip binaries, generated output, and secrets.

  2. 02

    Build bounded context

    Follow only the callers, types, tests, and project rules needed to prove or disprove a candidate.

  3. 03

    Challenge every finding

    A second pass checks the trigger, impact, causality, line range, and possible counter-evidence.

  4. 04

    Report the signal

    Return at most ten prioritized findings in Markdown or JSON. Clean changes get a clean result.

Quality is measured

No private victory lap

Buggy and clean patches, expected findings, and the scoring harness live in the repository. CI verifies the scorer; named host/model runs are required before publishing behavioral score claims.

SignalPrecision / Recall / F1

Start locally

Use the agent you already trust

Choose a platform. The default workflow adds no model gateway and sends no telemetry.

From the cloned repository, register it and install the Codex skill in one command.

npm run install:agents -- --platform codex

Then ask: $auto-code-review review my current changes

From the cloned repository, register it and install the namespaced skill in one command.

npm run install:agents -- --platform claude

Then run: /auto-code-review:review
